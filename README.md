# titanic-survival-prediction
Machine learning model to predict Titanic passenger survival
This is a project based on predicting titanic survival. I built a machine learning model to predict such using logistic regression. I used python, pandas and scikit-learn. The process involved me cleaning missing data and after using the logistic regression model. The results: accuracy (0.804_, precision (0.783), recall (0.730) and F1 score (0.755).
